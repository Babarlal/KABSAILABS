Unified Sales Analytics Dashboard for Winbid

The Challenge

Winbid’s sales team ran outbound calls and SMS across several disconnected tools. Performance data lived in separate exports, so leadership had no single, current view of what was working — and reporting ate a full day each week.

The Solution

We built one pipeline that pulls every call and message event into a unified warehouse, then surfaces it in a live dashboard. Reps, managers, and leadership each get the view they need, refreshed automatically.

How We Built It

Webhooks stream events from the calling platform into an n8n workflow that cleans and normalizes each record, lands it in BigQuery, and syncs roll-ups to a shared sheet for ad-hoc analysis.

  • Event capture via platform webhooks
  • Transformation and de-duplication in n8n
  • Warehousing in BigQuery for fast queries
  • Live dashboard layer on top

Results

Reporting that used to take a day now happens in real time, and the team finally trusts one number. Managers spot under-performing campaigns the same day instead of the next week.

Key Features

  • Real-time, unified view across every channel
  • Per-rep and per-campaign performance
  • Automated daily and weekly roll-ups
  • No manual exports or spreadsheet stitching

Technical Stack

n8n, BigQuery, Google Sheets, and the team’s existing calling and SMS platforms — connected via APIs and webhooks.

Future Enhancements

Next, an AI layer flags anomalies and drafts a plain-language summary of each week’s numbers, so managers get insight without reading a chart.

Conclusion

One connected pipeline turned a day of manual reporting into a live system the whole team trusts — the kind of foundation every data-driven sales org should have.
