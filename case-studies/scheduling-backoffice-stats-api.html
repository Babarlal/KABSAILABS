A scheduling back office with stats, safe reassignment and locked manual changes

One webhook gives an operator workload stats, a safe way to reassign a booking, the full roster and an HTML dashboard. Every manual change is locked so the scheduler never reverts it.

The problem

An operator running automatic scheduling still needs to see workload at a glance, move a booking by hand, and know the automation will not undo that change.

How it works

One webhook takes an action and returns the answer.

  • stats: tours, hours, passengers and days worked per helicopter and per pilot, plus the gap between the busiest and quietest.
  • reassign: checks the new pilot is not off and that neither the pilot nor the helicopter is double booked. If it passes, the booking is locked and marked as a manual override.
  • roster: the full schedule in time order with lock flags.
  • dashboard: a self-contained HTML screen.

A locked booking is skipped by the auto scheduler from then on. Weather postponements and cancellations are left alone the same way.

Verified run

Four live calls: stats over a 40 tour month, a valid reassignment that locked the booking, a reassignment to a pilot on their day off that was correctly rejected, and the dashboard served as HTML.

What a person still handles

  • Every reassignment decision.
  • Weather calls and cancellations.
