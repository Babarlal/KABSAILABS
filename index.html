Things we would rather not build

Half of the audits we run end with us telling the owner to keep the human, or to fix a spreadsheet first. Here are the rules we use.

  • If your phone rings fewer than 20 times a day, keep the receptionist.A voice agent costs more to run than the calls it saves at that volume. We'll tell you the number where it flips.
  • If the data lives in screenshots, we fix the data before anything else.Automating a broken input just makes the mess arrive faster.
  • If a task takes under two hours a week, it gets a checklist, not a system.A build has a setup cost and a monthly cost. Both have to be smaller than the problem.
  • If nobody will check the first month of outputs, we don't ship.Every system we build is watched by a person before it is trusted. That includes ours.
